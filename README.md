# Markettech.in E-commerce

A starter storefront for an owner-led kitchen and household goods business.

## Run the preview

This is a static, dependency-free front-end preview. Start a local server from this repository:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Then open the preview in your browser. The product catalogue, INR prices, cart, and saved items are sample/demo data stored only in the current browser. **Checkout is intentionally not connected and no real order or payment can be made.**
